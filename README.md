# Живые видеообои — каталог

Каталог для Android-приложения «Видеообои». Приложение читает `catalog.json`,
показывает обои по категориям и скачивает видео по нажатию.

Добавить обои (на Mac, из папки проекта):

```bash
.venv/bin/python tools/add_wallpaper.py ~/Downloads/video.mp4 --title "Название" --category it --publish
```

Видео: Mixkit (бесплатная лицензия) и сгенерированные `tools/generate_it.py`.
